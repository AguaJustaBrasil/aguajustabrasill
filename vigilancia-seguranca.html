🔒 Privacidade e segurança — Água Justa

Projeto independente.
O Água Justa não é a concessionária, órgão público, banco ou escritório de advocacia.

O que o formulário online faz

O formulário de solicitação foi desenhado para gerar um documento no próprio aparelho do usuário. Nesta versão, os dados digitados no formulário não são enviados automaticamente para o Água Justa e não são cadastrados em um banco de dados do projeto.

Dados necessários

Informe somente os dados necessários para identificar e fundamentar a solicitação. Revise o documento antes de salvá-lo ou enviá-lo.

O que nunca informar

  • senha de banco ou de aplicativo;
  • código recebido por SMS ou aplicativo;
  • senha do gov.br;
  • número de cartão e código de segurança;
  • chaves ou códigos de autenticação.

Antes de enviar qualquer documento

Confira se o endereço do site é realmente o canal oficial da instituição. Desconfie de pedidos de pagamento, urgência artificial ou promessa de liberar benefício mediante transferência.

LGPD

O projeto adota, nesta funcionalidade, o princípio de minimização: pedir somente o necessário para a finalidade informada. Caso uma futura versão passe a armazenar dados pessoais, a política deverá ser atualizada antes dessa mudança, com informação clara sobre finalidade, base legal, retenção, segurança e direitos do titular.

Importante: esta página é uma explicação operacional de privacidade e segurança do projeto e não substitui aconselhamento jurídico.
