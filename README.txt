Privacidade:
O formulário online é um gerador local: nesta versão, os dados digitados não são enviados automaticamente ao Água Justa.
Não solicitar senha, códigos de autenticação, dados bancários ou cartão.

Importante:
Os modelos são independentes. O usuário deve conferir o canal oficial e a competência antes de protocolar.
